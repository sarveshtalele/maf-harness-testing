6:

15: | `{repo}_report.md` | Architects, Confluence, Notion | GitHub-compatible Markdown (12 sections) |
16: | `{repo}_block_diagram.svg` | All audiences | Architecture layer diagram (SVG, embeddable) |
17: | `{repo}_dependency_graph.svg` | Engineers | Module dependency graph (SVG, embeddable) |
18: | `{repo}_evaluation.md` | QA, developers | Automated 100-point quality score |
19: | `manifest.json` | Automation, CI | Run metrics and file index |
20: 
21: **Supported languages:** Python · Java · C# / .NET · JavaScript · Typ
